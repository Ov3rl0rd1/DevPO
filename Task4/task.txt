Разработка профессиональных приложений Python

Практическое задание № 4
«Компоновка интерфейса. QML»


Практическое задание:
Требуется:
Перенести приложение из ПЗ2 на QML.

Задание 1. Перенос интерфейса на QML
Создайте новый вариант приложения «Карточка объекта учёта», используя QML для описания пользовательского интерфейса.
Интерфейс, ранее созданный с использованием виджетов PySide6, необходимо реализовать средствами Qt Quick и Qt Quick Controls.
При переносе необходимо сохранить общую структуру формы и назначение элементов интерфейса

Задание 2. Используемые элементы
Элементы приложения из практического задания № 2 необходимо заменить соответствующими элементами QML.
В интерфейсе должны присутствовать аналоги следующих элементов:
1.	текстовая надпись;
2.	поле ввода текста;
3.	выпадающий список;
4.	элемент для ввода числового значения;
5.	флажок;
6.	ползунок;
7.	кнопки управления.

Задание 3. Реакция интерфейса на действия пользователя

Необходимо реализовать обработку пользовательских действий средствами QML.
Интерфейс должен реагировать на изменение значений элементов непосредственно во время работы программы.
Необходимо подключить логику в UI.
Пример подключения: 
Button {
                id: startButton
                text: "▶  Запуск"
                enabled: simulationViewModel.canStart
                onClicked: simulationViewModel.start()
            }
